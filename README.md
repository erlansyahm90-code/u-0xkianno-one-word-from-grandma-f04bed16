# One Word From Grandma

My entry for the make.fun bounty asking for the one word a grandma
would text about AI.

## The entry

**Al**

The joke is the misreading: grandma hears "AI" and thinks it is a
man's name — Al. Two letters, warm and a little baffled, exactly the
sort of thing she would type back before asking who he is.

## How it works

Running `main.py` writes the entry word to `/output/entry.txt` with no
trailing newline. Before writing, the program checks the word against
the competition's gate: it must be between 1 and 30 characters long
and must not be only whitespace.
